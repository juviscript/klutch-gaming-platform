Requirements

Before You Install

  • Windows 10 or 11, 64-bit
  • A Klutch Gaming Compass connected via USB
  • No Java or other runtime needed — the app bundles its own

Windows SmartScreen Notice

Meridian isn't code-signed yet, so Windows will likely show "Windows protected your PC" on first launch. This is expected for a young open-source project — click More info, then Run anyway.

Firmware

Updating Your Compass

Meridian checks for new firmware on connect and links you to the changelog when one's available, but doesn't flash it automatically yet. To update manually:

  1. 1. Put the Compass into UF2 bootloader mode — it'll appear as a USB mass-storage drive.
  2. 2. Download the latest .uf2 file from GitHub Releases.
  3. 3. Drag the file onto that drive. The Compass will reboot automatically once it's done.
